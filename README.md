# ODipinjam — Sistem Manajemen Peminjaman & Inventaris Barang

Platform manajemen inventaris dan peminjaman barang berbasis peran (Admin & Anggota) dengan pelacakan ketersediaan real-time, kode QR, bulk import CSV/Excel, bukti foto, laporan bulanan, dan notifikasi email otomatis.

## Menjalankan Secara Lokal

**Prasyarat:** Node.js

1. Instal dependensi:
   ```bash
   npm install
   ```
2. Jalankan server pengembangan:
   ```bash
   npm run dev
   ```
3. Build untuk produksi:
   ```bash
   npm run build
   ```
